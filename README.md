# ExpenseFlow — Personal Expense Tracker

A Streamlit-based expense tracker with category suggestions, monthly budget tracking, spending charts, transaction search, and CSV export.

## Run locally

1. Install Python 3.10 or newer.
2. Open a terminal in this project folder.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the app:

   ```bash
   streamlit run app.py
   ```

The app stores transactions in `expenses_data.json` in the folder where it is run. Use sample/demo information and avoid entering sensitive financial details.

## Note

Category suggestions use simple keyword rules. They are not generated by a trained AI model.
